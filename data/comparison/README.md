# Comparison corpora

Controls for the Structure page. Each corpus is one CSV here:

```
# source: where the data came from (publication, licence)
# kind: linguistic        (or: non-linguistic)
text_id,signs
1,A B C
```

`signs` holds space-separated tokens in reading order. Use short texts of a similar length to Indus inscriptions (for example, early cuneiform labels, Linear B tablets, mason's marks, heraldic blazons) so the comparison is fair. Only commit corpora whose licence allows redistribution.
