# Sign marks: base sign and added marks (blind annotation)

`marks_blind_2026-10-20.csv` covers 490 signs. For each one it gives:
- `base`: the plainest sign it is built on, or "self";
- `marks`: from a fixed vocabulary (enclosure_strokes, brackets, roof, top_strokes_N, side_strokes_N, inner_line, inner_dot, crossbar, antennae, doubled, ligature, other);
- `confidence` and `note`.

**How it was made.** An agent annotated it on 20 October 2026, from glyph drawings in the SK Indus Script font, which uses the Wells/ICIT numbering. The agent was given **no** positional or corpus data and **no** hypothesis.

**One reader only:** the annotation should be checked by a second reader. Some signs look identical in the font; see the notes column.
