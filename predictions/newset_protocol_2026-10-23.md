# New-set batch: protocol, frozen before the set was analysed

*23 October 2026. Committed before `scripts/run_newset_confirmatory.py` is run. The batch runs once.*

## Data

- `data/icit_merged_paragorth/new_to_export_corpus.csv` (source key `icit_new_to_export`): 1,788 ICIT objects absent from this project's export (matched by CISI number; 215 re-transcriptions removed). Built from paragorth's merged Wells/ICIT copy (MIT).
- Only object counts by site, type, material and completeness were looked at before freezing. No sign statistic was computed on this set.
- **Not independent of ICIT** (same transcription project): results are 'held out from my export', not out-of-corpus.
- Only 388 objects are marked complete (the export itself holds only complete texts). Rule fixed here: **position tests use complete texts only; neighbour tests keep incomplete texts.** Replications keep their own frozen settings (all drop damaged texts).

## Analysis

- One run of `scripts/run_newset_confirmatory.py`. Permutation p-values, one-sided as frozen in each record.
- Benjamini-Hochberg across all tests in this batch (A + B). Verdicts as in the project (`Supported` if q < 0.05 with support ≥ 5).
- Every result is reported, including failures. A replication failure does not erase the original holdout result; both are reported side by side.
- The sealed new-finds predictions (P1–P9) are not consumed: P9's exact statistic is run here as a new hypothesis, and P1–P9 stay open for genuinely new publications.
