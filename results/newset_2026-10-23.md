# New-set batch: results (held out from the export)

*The fish result is published as a preprint: Toppe (2026), "An inside mark stops the Indus fish sign from being counted: a pre-registered test on held-out inscriptions", Zenodo, [doi:10.5281/zenodo.23607038](https://doi.org/10.5281/zenodo.23607038).*

*23 October 2026. Protocol and all hypotheses committed in `d010b9a` (13:48:59 −04:00) before the set was analysed: `predictions/newset_protocol_2026-10-23.md`. One run of `scripts/run_newset_confirmatory.py`. Raw output: `newset_2026-10-23.json`. BH within this batch (24 tests with a p-value).*

**Data.** 1,788 ICIT objects missing from this project's export (`data/icit_merged_paragorth/`), never used in any analysis here. Not independent of ICIT. Only 388 are marked complete, so position tests ran on **271–380 texts** (complete, deduplicated), fewer than the old holdout. Neighbour tests ran on **1,225 texts** (incomplete kept, deduplicated).

## Headline: the fish lead is confirmed

| | Exploration | New set |
|---|---|---|
| Plain fish G220 preceded by a numeral | 37% (67/181) | **30% (33/110)** |
| Inside-marked fish (G231, G233, G244) preceded by a numeral | 12% (17/147) | **6% (4/68)** |
| Difference | +0.25 (p 0.0002) | **+0.24 (p 0.0002, q 0.002)** |
| **Verdict** | — | **Supported** |

The plain fish is a counted item; the fish with an inside mark is almost never counted. On unseen texts the effect is the same size. This is the first held-out evidence that an **inside mark changes what kind of thing a sign is**, not just how it is drawn. It fits Erin's idea that the inside gives the function, though the test cannot say which function.

## What this means

- **The core grammar replicates** on texts never used: the heading–middle–closer layout, the jar ending, the recurring units and the numeral pairings.
- **Marks:** the fish result is now the firmest evidence that inside marks change meaning. Top marks and P9 pointed the right way but this set was too small in complete marked texts to confirm them.
- **Dropped:** counted vs formula items.
- **Limit:** the complete-text part of this set is small (271–380 texts), so most position replications were underpowered; a "not supported" here is weak evidence.

## Robustness after the run: Mahadevan's transcription (IM77)

*Script `scripts/fish_numeral_im77.py`, output `fish_numeral_im77_output.txt`. Not confirmatory: IM77 covers largely the same objects as ICIT. Signs via paragorth's unvalidated ICIT→Mahadevan bridge (G220 → M59, G231 → M70, G233 → M72).*

The fish lead holds in an independent transcription: the plain fish is preceded by a numeral 34% of the time (130/381), the inside-marked fish 8% (21/261); difference +0.26, p 0.0002. So the result does not come from ICIT's reading conventions.
