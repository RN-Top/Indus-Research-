# Does the feeding trough go with different texts? (scouting, exploration split only; not locked)

*29 October 2026. Script `scripts/trough_scouting.py`, output `trough_scouting_output.txt`. Prompted by Mukhopadhyay (2023, HSSC 10:972, p. 17), who reads the trough in front of an animal as marking a "tax-receiving" entity and notes that the elephant sometimes faces one and sometimes not.*

**Prediction.** If the trough marks a role, then for the same animal, seals with a trough should carry different texts from seals without one. The two-layer reading (paper 3) predicts no difference.

**What the exploration split shows.**
- **The trough belongs to the animal, not to a role.**

  | Animal | With trough / all |
  |---|---|
  | Gaur | 47 / 53 |
  | Tiger | 7 / 7 |
  | Buffalo | 4 / 5 |
  | Rhino | 9 / 14 |
  | Elephant | 1 / 21 |
  | Zebu | 0 / 20 |
  | Unicorn | never (it has the standard instead) |

  The wild animals get the trough. The zebu and almost every elephant do not.
- Only 4 animal × site cells have both kinds, all at Mohenjo-daro. That gives 66 seals in total, but only 20 without a trough, so the comparison is very thin.
- In those cells, texts with and without a trough are **no more different than chance**:

  | Part of the text | Divergence (observed) | Chance | p |
  |---|---|---|---|
  | All signs | 0.63 | 0.73 | 0.97 |
  | First sign | 0.79 | 0.88 | 0.96 |
  | Last sign | 0.56 | 0.69 | 0.85 |

**Decision: not locked.** The holdout would hold about a quarter as many seals, with fewer than 15 in the smaller group. That is below the project's minimum support, so a frozen test could not pass whatever the truth. It would also use up a slot in the multiple-testing correction for nothing.

**Reading.** In the data we have, the trough is part of how each animal is drawn: almost always present for some animals, almost never for others. It is not a switch that changes with the text. This fits the two-layer model and gives no support to the trough-as-role idea. The test is underpowered, though, so it cannot rule that idea out.
